# ECR3000.md — Glyph Field Crystallization Spec

## Crown Thesis

ECR-3000 is a deterministic symbolic-field runtime where glyph agents compete, inhibit, lock, unlock, revise, and crystallize output under receipt-backed validation.

**The runtime is the model.**

## Core Primitives

### Glyph Agents

Each character is a persistent live process with:
- **Phase**: oscillation phase (determines activation timing)
- **Frequency**: oscillation rate (determines processing speed)
- **Excitation**: current activation level
- **Refractory state**: cooldown after firing (prevents repetition)
- **Memory**: local context from previous iterations

### Field Dynamics

- **Competition**: multiple glyphs compete for the same position
- **Inhibition**: active glyphs suppress competitors (refractory inhibition)
- **Locking**: stable regions lock (no further revision)
- **Unlocking**: new evidence or pressure can unlock a region
- **Crystallization**: the output emerges as the most stable configuration

### Key Differences from Transformers

| Property | Transformer | ECR-3000 |
|----------|------------|----------|
| Generation | Left-to-right | Field-wise revision |
| Attention | Softmax | Equilibrium convergence |
| Tokens | Discrete input | Phase-locked coalitions |
| Compute | Fixed (per token) | Variable (by convergence time) |
| Meaning | Predicted | Crystallized (most stable config) |
| Agents | None | Dumb agents with local state |
| Intelligence | In weights | In field dynamics |
