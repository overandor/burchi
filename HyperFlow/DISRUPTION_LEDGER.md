# DISRUPTION_LEDGER.md — Ranked Disruption Primitives

> **Ledger principle**: disruption distance and dollar appraisal are not the same thing. Distance measures how far a primitive is from mainstream public development. Appraisal measures what the repository can defensibly claim today based on proof artifacts, tests, receipts, and working code.

> **Scientific correction**: Neighboring components already exist publicly:
> - SpikeGPT uses binary event-driven spiking activation units for language modeling ([arXiv:2302.13939](https://arxiv.org/abs/2302.13939))
> - SpikeLLM scales spiking mechanisms into LLM-style systems
> - NeuronSpark explores a 0.9B pure spiking language model
> - NCA language-model work explores synthetic cellular-automata data for pre-pretraining
>
> These do **not** equal the stronger claim: deterministic glyph agents, symbolic field crystallization, runtime-as-model, locks, compiler pressure, receipts, and reproducible convergence traces. The complete integration is the real claim.
